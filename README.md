# Ish kuzatuv
CNC / shirma ishlarini kuzatish dasturi (React + Vite + Supabase). Sayt (Revo) alohida loyihada.

1. Supabase SQL Editor'da `supabase-sozlash.sql`, `supabase-yangilash-area.sql`, `supabase-foydalanuvchilar.sql` fayllarini ishga tushiring.
2. Edge Function: `supabase-functions/manage-users/index.ts` (nomi `manage-users`).
3. Vercel: GitHub repo'ni ulang (Framework: Vite). Ilova asosiy manzilda kirish oynasini ochadi.

Kompyuterda: `npm install` va `npm run dev`.
